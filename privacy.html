プライバシーポリシー

「探偵業届出書 作成ツール」（以下「本ツール」）における、入力情報の取扱いについて説明します。

1. 入力していただく情報の取扱い

本ツールは、届出書の作成に必要な氏名・住所・生年月日などの情報を画面上で入力していただきますが、これらの情報は、お使いの端末（ブラウザ）内でのみ処理されます。届出書作成のために入力していただいた内容が、運営者のサーバーその他の外部サーバーへ送信されることはありません。会員登録の仕組みも設けていません。

なお、本ツールの内容についてのご意見・お問い合わせ用に、別途「運営者情報・お問い合わせ」ページにフォームを設けています。このフォームに入力・送信された内容（お名前・メールアドレス・お問い合わせ内容）は、フォーム送信サービスである Formspree を経由して運営者に届きます。届出書の作成画面で入力する氏名・住所等とは別の仕組みであり、お問い合わせフォームを利用しない限り、外部に送信される情報はありません。

2. ブラウザ内保存（ローカルストレージ）について

入力途中の内容を後日引き続き編集できるよう、ブラウザの「ローカルストレージ」という仕組みを使って、お使いの端末の中だけに一時的に保存します。この情報は運営者を含む第三者が閲覧・取得することはできません。保存された内容を削除したい場合は、各様式ページの「最初からやり直す」ボタンを押すか、ブラウザの設定からサイトデータを削除してください。

また、入力内容をファイル（JSON形式）として、お使いの端末にダウンロード・保存する機能を用意しています。このファイルも運営者には送信されません。ファイルの管理は利用者ご自身の責任で行ってください。

3. 本ツールが利用している外部サービス

本ツールは、次の外部サービスを利用しています。これらのサービスは、それぞれのプライバシーポリシーに基づいてアクセス情報（IPアドレスなど）を取得する場合があります。

  • GitHub Pages（本サイトの公開・配信基盤）
    本サイトは GitHub, Inc. の GitHub Pages を利用して公開されています。サイトへのアクセスに伴い、GitHub 側で標準的なアクセスログ等が記録される場合があります。詳しくは GitHub プライバシーステートメント をご覧ください。
  • Google Fonts（文字の表示）
    本サイトの文字（フォント）表示のために、Google LLC が提供する Google Fonts を利用しています。フォントの読み込み時に、Google 側でアクセス情報が取得される場合があります。詳しくは Google プライバシーポリシー をご覧ください。
  • Formspree（お問い合わせフォームの送信）
    「運営者情報・お問い合わせ」ページのフォームは、Formspree, Inc. が提供するフォーム送信サービスを利用しています。フォームに入力・送信した内容（お名前・メールアドレス・お問い合わせ内容等）は、Formspree を経由して運営者に届きます。詳しくは Formspree プライバシーポリシー をご覧ください。

本ツールでは、上記以外のアクセス解析ツールや広告配信の仕組みは使用していません。

4. Cookie（クッキー）について

本ツールは、利用者を識別するための独自のCookieを発行していません。上記の外部サービスの利用に伴い、各サービス側でCookie等が使用される場合があります。

5. お問い合わせについて

本ツールの内容（不具合のご連絡、ご意見・ご要望など）についてのお問い合わせは、運営者情報・お問い合わせページのフォームから承っています。なお、届出の記載方法や添付書類など、提出手続そのものについて不明な点がある場合は、提出先となる警察署（生活安全課等）にお問い合わせください。

6. 本ポリシーの変更

本ポリシーの内容は、必要に応じて予告なく変更することがあります。変更後の内容は、本ページに掲載した時点から適用されます。
