# 探偵業届出書 作成ツール

探偵業の業務の適正化に関する法律に基づく届出書等（様式第1号〜第4号）を、画面の質問に答えるだけで作成できる静的サイトです。サーバー・バックエンドは一切不要で、GitHub Pages でそのまま公開できます。

## 含まれるページ

| ファイル | 内容 |
|---|---|
| `index.html` | トップページ（4様式＋解説ページへの入口） |
| `form1.html` | 様式第1号：探偵業開始届出書 |
| `form2.html` | 様式第2号：探偵業廃止届出書 |
| `form3.html` | 様式第3号：探偵業変更届出書 |
| `form4.html` | 様式第4号：標識 |
| `guide.html` | 探偵業法の解説・解釈 |
| `terms.html` | 利用規約（免責事項を含む） |
| `privacy.html` | プライバシーポリシー（**検索エンジン非公開**：`<meta name="robots" content="noindex,nofollow">`指定済み） |
| `sitemap.xml` | サイトマップ（`privacy.html` は意図的に含めていません） |
| `robots.txt` | `privacy.html` のみクロール禁止、他は許可 |
| `assets/style.css` | 共通スタイル（背景白、様式ごとにアクセントカラー） |
| `assets/common.js` | 都道府県／公安委員会名データ、保存・書き出しユーティリティ |
| `assets/wizard.js` | 質問形式ウィザードの共通エンジン |

## 特徴

- **通信不要**：入力データはブラウザ内（localStorage）とファイル書き出し（JSON）のみで扱われ、外部サーバーには送信されません。問い合わせフォームもありません。
- **途中保存・再開**：この端末への自動保存に加えて、入力内容をJSONファイルとして書き出し、別の端末で読み込んで再開することもできます。
- **後から修正可能**：確認画面から各ステップに戻って何度でも編集できます。
- **都道府県対応**：様式自体は全国共通の法定様式（岡山県警察公表のものに準拠）ですが、都道府県を選ぶとあて先の公安委員会名が自動反映されます。
- **印刷・PDF保存**：確認画面の「印刷してPDFとして保存する」ボタンからブラウザの印刷機能でPDF化できます（A4想定のレイアウト）。

## GitHub Pages への公開手順

1. GitHub で新しいリポジトリを作成します（例：`tantei-todokede-tool`）。
2. このフォルダ内の全ファイルをリポジトリのルート（またはお好みで `docs/` フォルダ）にアップロードし、コミット・プッシュします。
3. リポジトリの **Settings → Pages** を開き、Source を「Deploy from a branch」、Branch を `main`（アップロード先のフォルダ）に設定して保存します。
4. しばらくすると `https://ユーザー名.github.io/リポジトリ名/` で公開されます。
5. 公開URLは `https://leben-k.github.io/tantei/` に確定し、このファイル一式にはすでに反映済みです（`canonical`タグ、`sitemap.xml`、`robots.txt`）。リポジトリ名やユーザー名を今後変更した場合のみ、再度置き換えが必要です。
6. 独自ドメインを使う場合は、リポジトリ直下に `CNAME` ファイル（中身はドメイン名1行）を追加してください。

## 内容の更新について

様式の内容は、本ツール作成時点で確認できた岡山県警察の公表様式および関連する公表情報をもとに構成しています。法令改正等により様式が変更される場合がありますので、公開後も定期的に岡山県警察等の公式ページと照らし合わせてご確認ください。
